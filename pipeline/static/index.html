Run configuration

α → 0 gives each vehicle a single condition; α → ∞ gives them all the same mixture, which is IID.

Size skew makes vehicles hold unequal amounts, on top of whichever partition is chosen — 0.5 is mild, 1.5 an order of magnitude. The fleet total is unchanged, so a skewed run is still budget-comparable with an unskewed one.

Vehicles train serialised. One client peaks at 15.9 GB of 16.3 GB, so running them together would run out of memory. Wall clock scales with vehicle count.
